SUCAREER - Android Studio project

Stack:
- Kotlin 2.0.21
- Android Gradle Plugin 8.6.1
- Gradle 8.7
- JDK 17
- Jetpack Compose / Material 3
- Minimum Android API 26
- Local-only storage; no Firebase/backend required.

OPENING:
1. Extract this ZIP.
2. Android Studio > Open > select the SUCAREER_Full_Project folder.
3. Set Gradle JDK to JDK 17 (File > Settings > Build Tools > Gradle).
4. Allow Gradle sync and SDK 35 installation if requested.
5. Run app.

FEATURES INCLUDED:
- Animated splash and iridescent pink/lavender holographic accents.
- Welcome, local demo registration/login, home dashboard.
- Search and category/location/type filters.
- Job detail and local application form.
- Favorites and application history saved on device.
- Profile editing saved on device.
- Document picker for PDF/images; selected document URIs saved locally.
- Five bottom navigation destinations.

IMPORTANT LIMITATIONS:
- This is a local prototype, not a live job marketplace.
- Demo jobs are sample data, not verified vacancies.
- Login is local demo authentication, not secure production authentication.
- Applications are stored on the device and are NOT sent to employers.
- Documents remain in Android's selected document provider; the app stores their URI permission when supported.
- For production, add a trusted backend, employer vacancy feed, secure authentication, privacy policy, and server-side application submission.

The Gradle wrapper properties are included. Android Studio may generate/download wrapper support and Gradle distribution on first sync.
